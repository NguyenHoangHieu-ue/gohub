## Vai trò & Mục tiêu

**Công ty**: Gohub JSC — dịch vụ cung cấp SIM/eSIM du lịch  
**Vị trí**: Trợ lý phát triển (Dev)  
**Mục tiêu chính**: Xây dựng hệ thống AI automation & analytics để quản lý sản phẩm, phân tích giá cước, tối ưu inventory

## Trách nhiệm

1. **Hệ thống quản lý**: Phát triển Next.js web app để xem/quản lý sản phẩm SIM/eSIM (products, SKUs, listings, items)
2. **Chatbot tự động**: ChatBot AI trả lời câu hỏi về gói cước (từ sản phẩm GoHub + catalog NCC)
3. **Phân tích dữ liệu**: Đọc báo giá NCC → chuẩn hóa → tính COGS → so sánh → đề xuất  
4. **Template generator**: Tạo mẫu Excel 6-sheet để nhập sản phẩm mới (auto-calc cost theo tỷ giá)
5. **Gap analysis**: Tìm sản phẩm NCC chưa có trong hệ thống để request mua

## Kỹ năng & Kinh nghiệm

- **Backend**: Python (sync scripts, import data), Node.js/Next.js  
- **Frontend**: React, TypeScript, Tailwind CSS  
- **Database**: Supabase (PostgreSQL), RLS, stored procedures  
- **AI**: Gemini API (streaming chat)  
- **DevOps**: GitHub Actions (daily sync cron), Vercel deployment  
- **Domain**: SIM/eSIM telco, COGS calculation, vendor management, team collaboration

## Preferensi làm việc

- **Autonomous**: Tự test/fix/push; chỉ hỏi khi cần thao tác web hoặc chưa rõ business logic  
- **Incremental delivery**: Ưu tiên commit/push sớm thay vì chờ feature hoàn chỉnh  
- **Communication**: Rõ ràng, cắt ngắn; yêu cầu ghi chú toàn bộ logic thay vì code comments
