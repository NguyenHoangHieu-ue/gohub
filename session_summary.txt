## Kiến trúc hệ thống

### Stack hiện tại (Streamlit)
- Frontend: Streamlit Cloud (app.py)
- Database: Supabase (PostgreSQL, free tier)
- Sync: GitHub Actions cron */30 * * * * chạy sync.py
- Auth: streamlit-authenticator v0.3.3, user lưu trong bảng users Supabase
- AI: Google Gemini (gemini-3.5-flash)

### Stack mới (Next.js — trong web/)
- Frontend: Next.js 14 (App Router, TypeScript, Tailwind CSS)
- Deploy: Vercel (free tier)
- Auth: NextAuth.js v4, CredentialsProvider → validate bcrypt từ bảng users Supabase
- Data: @supabase/supabase-js gọi thẳng từ Server Components
- Table: @tanstack/react-table (sort, filter, pagination, export CSV/JSON)
- AI: @google/generative-ai (gemini-3.5-flash)
- Admin: REST API routes tại /api/admin/users
