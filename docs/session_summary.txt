## Session 54 — tiếp 3 (2026-06-15) — 3HK FUP pricing formula (commits ea81e58, fc1acb2)

### File mới: `docs/wiki/pricing/3HK-Custom-Package-Pricing.md`
Tài liệu định giá cho gói cấu trúc FUP: **X GB tốc độ cao + Y GB FUP @ Z Mbps**

**Insight chính:**
- Tách COGS thành 2 thành phần: util_hs (highspeed) + util_fup (FUP riêng)
- util_fup > util_hs vì FUP chỉ dùng khi đã hết hs cap → user đang cần data → dùng nhiều hơn
- Chi phí 3HK giữa các mức throttle không chênh nhiều, nhưng giá trị với khách chênh lớn → cơ hội tier pricing
- FUP > 2GB @ 1Mbps thường không hiệu quả → nên tăng highspeed cap thay vì tăng FUP

**Bảng hệ số:**
- util_hs: 70–90% theo cap size (cap nhỏ utilization cao)
- util_fup: 35–88% theo (FUP size, throttle speed)
- Hệ số giá trị FUP vs highspeed: 2Mbps=60%, 1Mbps=45%, 512kbps=25%, 128kbps=10%

**Tier system gợi ý (7 ngày, Châu Á, margin ~40%):**
Starter (1+0.5GB 512k) → Basic (1+1GB 1M) → Standard (2+1GB 1M) → Pro (3+1GB 1M) → Pro+ (3+2GB 1M) → Max (5+2GB 2M)

- GoHub codes phải có chữ số (AP2, EU1) hoặc user gõ hoa sẵn (CHM, APA)

### Kiến trúc Agent System
```
User message → [Router] → [Agent] → tool calls → Supabase → Gemini stream → UI
```

**Router**: hybrid (rule-based fast path + Gemini fallback)
**Agents**: 5 agents chuyên biệt, mỗi agent có system prompt + tool declarations riêng
**Tools**: function calling thật (Gemini gọi tool → server execute → trả kết quả → Gemini generate)
**UI**: chat bubble + agent badge per message + loading indicator tên agent

### 5 Agents

| Agent | Trigger | Tools | Roles |
|---|---|---|---|
| Tư Vấn | Tìm gói đi nước X | searchSkus, getCountryInfo, getProductDetail | All |
| Tra Cứu | Hỏi chi tiết SKU/product cụ thể | getSkuByCode, getListings, decodeSkuCode | All |
| Giải Đáp | Hỏi nghĩa mã, quy trình, hệ thống | getVendorInfo, getCountryInfo, decodeSkuCode | All |
| Giá/COGS | Hỏi giá, COGS, tỷ giá | getFxRates, getSkuCogs, calculate3hkCogs | admin/manager |
| Gap Analysis | NCC có gì HT chưa có | searchNccWm, searchNcc3hk, findGaps | admin/manager |
