### Performance
- Products/SKUs/Listings: unstable_cache 30 phút → lần đầu fetch Supabase, lần sau tức thì
- Items: server-side search qua /api/items, 50 rows/trang, filter đa chiều

### Data loading
- Products (769): fetchAll → cache 30 phút
- SKUs (10,957): fetchAll → cache 30 phút, filter client-side với ExtraFilter
- Listings (10,674): fetchAll → cache 30 phút
- Items (130k active): server-side search, không cache (real-time filter)

### Filter
- DataTable có ExtraFilter type: "select" (dropdown) hoặc "range" (min/max input)
- SKUs dùng ExtraFilter: SIM/eSIM, product_type, throttle_speed, day_amount, data_amount
- Items page: custom filter UI → gọi /api/items

### Cấu trúc mã (từ Item-SKU Format.xlsx)
SKU CODE (13 ký tự) = [PurchaseType(1)][ProductType(1)][Country(3)][Vendor(2)][DataType(1)][DataAmount(3)][DayAmount(2)]
ITEM CODE (18 ký tự) = [Channel(1)][Partner(2)][PricelistCode(2)][SKU_CODE(13)][Number(2)]
- Channel: B=B2C, D=OD, W=WS, I=Internal
- Partner: SP=ShopeePay, MM=Momo, ZP=Zalopay, KK=KKday, T1=Tier1 WS
- PurchaseType: 1-6=VN variants, A-E=US variants
- Country: VNM=Vietnam, CHM=China-HK-Macao, ...

### Kiến trúc Agent System
```
User message → [Router] → [Agent] → tool calls → Supabase → Gemini stream → UI
```

**Router**: hybrid (rule-based fast path + Gemini fallback)
**Agents**: 5 agents chuyên biệt, mỗi agent có system prompt + tool declarations riêng
**Tools**: function calling thật (Gemini gọi tool → server execute → trả kết quả → Gemini generate)
**UI**: chat bubble + agent badge per message + loading indicator tên agent

### 5 Agents

| Agent | Trigger | Tools | Roles |
|---|---|---|---|
| Tư Vấn | Tìm gói đi nước X | searchSkus, getCountryInfo, getProductDetail | All |
| Tra Cứu | Hỏi chi tiết SKU/product cụ thể | getSkuByCode, getListings, decodeSkuCode | All |

| Gap Analysis | NCC có gì HT chưa có | searchNccWm, searchNcc3hk, findGaps | admin/manager |
